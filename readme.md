# Flood Prediction / Прогнозирование наводнений

Проект является проектной практикой студентов УрФУ.  

**Описание проекта**  
Данный проект посвящен разработке модели предсказания вероятности наводнения на основе данных Kaggle (Playground Series S4E5). Основной фокус на оптимизации: достижение наивысшего (R2 score) при минимальных вычислительных затратах.  
В ходе исследования было выявлено, что 3 синтетических признака (в том числе мета-фича обученная на логистической регрессии и извлеченная с помощью метода predict proba, которая итого получила первое место в больщинстве моделей в рамках Feature Importance) объясняют дисперсию данных лучше, чем 20 исходных факторов.  
Итого обучены порядка 9 моделей.  

**Как запустить:**  

Клонируйте репозиторий:  
git clone [https://github.com/your_username/flood-prediction.git  ](https://github.com/Mortelnik/navodnenie)

Установите зависимости:  
pip install -r requirements.txt  

Запустите Jupyter Notebook  
Flood_final.ipynb

Проект успешно демонстрирует, что глубокий анализ данных и грамотный Feature Engineering позволяют строить легкие и быстрые модели, не уступающие по точности сложным ансамблям на больших данных
